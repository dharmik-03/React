## ✨ Features

### 📊 Dashboard & Student Management
- View all registered students.
- Display student records in a clean table layout.
- Search students by name or GR ID.
- Filter students by course.
- Pagination for easy navigation.

### ⚙️ CRUD Operations

| Operation | Description |
|---|---|
| Create | Add new student records with validation. |
| Read | View student lists and complete details. |
| Update | Edit existing student information. |
| Delete | Delete student records with confirmation. |

### 📝 Student Information

Each student record contains:

- **Student Name:** Full name of the student.
- **GR ID:** Unique student registration number.
- **Course:** Full Stack Development, Graphic Design, or UI/UX.
- **Mobile Number:** Validated 10-digit mobile number.
- **Database ID:** MongoDB-generated `_id`.

### 🎨 UI & Design
- Modern and professional interface.
- Deep Navy Blue, White, and Light Gray color palette.
- Responsive layout for desktop, tablet, and mobile.
- Lucide outline icons.
- Clean typography and user-friendly forms.
- No unnecessary avatars or profile images.

### 🔗 Backend & Database
- MongoDB as the database.
- Backend APIs as the source of truth.
- Real-time CRUD operations through backend APIs.
- No fake data or local storage placeholder records.
